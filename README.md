# 字在 Zizai

> 打字这件事，不该把你的话交给别人。

字在（Zizai）是一个用 **Rust** 开发的拼音输入法（Windows）。整句输入、简拼、拼写纠错、双拼、英文模式，
全部在本机完成——**不上传任何数据，没有账号，没有统计上报，不联网检查更新。**

## 隐私

输入法能看到你敲下的每一个字：聊天、密码框旁边的备注、还没发出去的邮件。所以字在的默认答案是**什么都不往外发**。

- **转换在本机。** 拼音切分、词库查询、整句转换、候选排序、学习记录，全部是本地计算，不需要网络。
- **没有服务器。** 字在没有自己的后端，因此不存在「上传到字在」这回事。没有账号，没有遥测，没有崩溃上报。
- **密码框不工作。** 密码框与应用声明为私密的输入框里，不联想、不记录、不学习。
- **日志在本机、可关可清。** 缺省级别不记录输入内容；测试版的输入日志只写本机，用于离线评测，「高级」页可随时关闭或清空。
- **开源可核对。** 全部代码在这个仓库，上面每一条都可以自己读代码确认。

细节见文档 [数据与日志](https://qingjian.app/docs/help/data-and-logs)。

## 为什么用 Rust

输入法是一个常驻进程，被加载进你用的每一个程序里，每一次按键都要在几毫秒内给出候选。这个位置对内存安全和稳定性的要求，
和它拿到的数据一样敏感。

- **没有内存安全问题这一类崩溃。** 输入法崩了会把整个应用拖下水，Rust 在编译期就排除了这类问题。
- **一份 Core，多个平台。** 输入引擎完全平台无关，各平台只负责接系统接口和画候选窗口。
- **启动快、占用小。** 词库是内存映射的二进制格式，按音节位置二分查询，不需要常驻一份解析结果。

## 为什么叫「字在」

「字在」首先是一句事实：转换、排序、学习与个人数据都留在自己的电脑上。

它也与「自在」同音。输入法应该理解上下文、适应用户，但不要求账号，不用广告和云端依赖换取顺手。

这个名字不把产品限制在某一种输入方案或语言上。字在首先面向中文使用者，未来也可以承载更多输入方式。

## 功能

- **整句输入。** 连续敲完一整句再上屏，`jintiantianqihenhao` 首选即为「今天天气很好」；简拼 `jttqhh` 同样可用。
- **本地整句模型。** 停顿后由本机的小模型重排前几条路径，不联网。
- **拼写纠错。** 敲错的音节也能出正确的词，接受过的纠正会被记住。
- **双拼与注音。** 小鹤、自然码、微软、搜狗双拼；小鹤辅码；另支持大千注音。
- **英文模式。** 单击 `Shift` 或 `Caps Lock` 切换，字母直接进输入框、不出候选窗；中文模式下打英文词照样给英文候选。
- **自绘候选窗。** 候选窗、拼音行、状态条由自带的渲染器画，各平台一致。
- **学你怎么打字。** 选词、造词、词与词的接续都在本机记录并影响排序，可以随时关掉或删干净。

## 平台

核心输入引擎平台无关，壳只负责接入系统输入接口与候选窗口。目前只有 Windows 壳：

```text
Windows  → Text Services Framework (TSF)
```

输入引擎跑在独立的 Server 进程里，DLL 只负责 TSF 与画候选窗（见 `apps/windows/README.md`）。

---

## 不打算做什么

- 不做账号体系，不做云同步。
- 不在候选窗口里塞广告、推送、热词榜、皮肤商店。
- 不为任何功能牺牲输入延迟。
- 不做「大而全」：一个把拼音变成中文这件事做好的输入法，比一个什么都能干的输入法有用。
