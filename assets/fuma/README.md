# 辅码表（字级形码）

双拼辅助码（辅码）用的字级形码表：每行一条 `字=两码`，两码均为小写字母，
第一码是字的第一个部件、第二码是第二个部件（各按其读音取声母键）。
仅用于候选的辅码过滤，不参与组句；词组的辅码不存表，运行时按
「首字第 1 码 + 末字第 1 码」现算（与水杉输入法引擎 `HelpcodeUtils` 的语义一致）。

## 内容

| 文件 | 方案 | 条目 | 说明 |
| --- | --- | --- | --- |
| `xiaohe.txt` | 小鹤形码 | 8280 字（含 〇 与扩展区 280 字） | 每行 `字=两码`，UTF-8，无 BOM |

同一字重复出现的 3 条（艨 `vn`/`vu`、冔 `ky`/`oy`、奘 `pd`/`vd`，均为罕见字的两拆写法）
按上游行为**后一条覆盖前一条**。
