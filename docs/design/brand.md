# 「字在」品牌与界面视觉

这页是 Windows 产品界面的视觉约束。内部 crate、二进制、配置键与旧数据目录仍使用 `qingjian` / `Qingjian`，属于升级兼容面；用户看到的产品名是「字在 Zizai」。

## 名字与主张

「字在」既指文字与个人数据留在本机，也与「自在」同音。品牌句是：

> 字在本机，表达自在。

图标由四部分组成：宝盖的横势、一个字、输入光标、开放的候选框。不要再使用竹简、锁、盾牌、云或 AI 闪光作为主品牌图形。

矢量源文件在 `assets/icon/logo.svg`；`assets/icon/generate.py` 生成运行时 PNG 与 Windows ICO。

## 颜色语义

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 品牌强调 | `#3157D8` | `#6B8BFF` | 当前模式、主要选中态 |
| 选中背景 | `#E8EEFF` | `#25375F` | 当前候选 |
| 输入 / 本地 | `#55D6C2` | `#55D6C2` | preedit 光标、本地生效指示 |
| 云服务 | `#32B5E9` | `#38BDF8` | 云候选与云朵；不能代替品牌色 |
| 生词 | `#F59E0B` | `#FBBF24` | 尚未熟悉的译词 |
| 纠错 | `#E46D6D` | `#F38B8B` | 被替换的原输入与删除线 |
| 背景 | `#F7F6F2` | `#172033` | 候选窗、状态条 |
| 正文 | `#172033` | `#F7F6F2` | 候选词 |
| 次级文字 | `#667085` | `#B8C0D0` | 译文与说明 |
| 弱化文字 | `#98A2B3` | `#7F8A9E` | 序号与词性 |

薄荷色只表示「正在输入 / 本地生效」，天蓝色只表示可选云服务。状态条的当前模式使用品牌强调色，不能复用云色。

## 界面规则

- 候选窗不放 logo；品牌通过配色、圆角与薄荷色输入光标体现，候选内容始终优先。
- 横排、竖排、浅色、深色与 GDI 退路使用相同的颜色语义。
- 每次按键后的窗口更新不做入场、缩放或弹跳动画。
- 设置程序保留 Windows 原生控件与导航结构；品牌出现在窗口图标、导航标题、实时预览与关于页。
- 任务栏 / 语言栏的 16 px 模式图标使用单独绘制的「中 / A」，不直接缩小主图标。
- 安装包、开始菜单与设置程序共用主图标。卸载入口可用单色轮廓版；不要把下载箭头、箱子或 UAC 盾牌画进主图标。
- Windows 高对比模式由系统颜色接管；不能只靠颜色表达云端、生词或纠错状态。

## 兼容边界

品牌切换不同时迁移 `%APPDATA%\Qingjian`、`%LOCALAPPDATA%\Qingjian`、`Program Files\Qingjian`、`.qj` 格式名、Cargo 包名、可执行文件名与注册标识。它们需要单独的迁移方案，避免升级后丢学习数据、重复启动 Server 或留下两个输入法 profile。
