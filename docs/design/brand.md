# 「字在」品牌与界面视觉

这页是 Windows 产品界面的视觉约束。内部 crate、二进制、配置键与旧数据目录仍使用 `qingjian` / `Qingjian`，属于升级兼容面；用户看到的产品名是「字在 Zizai」。

## 名字与主张

「字在」既指文字与个人数据留在本机，也与「自在」同音。品牌句是：

> 字在本机，表达自在。

图标由四部分组成：宝盖的横势、一个字、输入光标、开放的候选框。不要再使用竹简、锁、盾牌、云或 AI 闪光作为主品牌图形。

矢量源文件在 `assets/icon/logo.svg`；`assets/icon/generate.py` 生成运行时 PNG 与 Windows ICO。

## 界面规则

- 候选窗不放 logo；品牌通过配色、圆角与薄荷色输入光标体现，候选内容始终优先。
- 横排候选窗在浅色与深色模式下使用相同的颜色语义。
- 每次按键后的窗口更新不做入场、缩放或弹跳动画。
- 设置程序使用 egui 的紧凑导航与列表，标题栏也由 egui 自绘；标题栏、导航、控件、主题卡、候选窗与状态条同步使用当前色系。
- 设置程序标题栏、导航品牌头与「关于」页的 Logo 保持同一轮廓，但按当前色系与系统明暗实时换色：浅色使用主题强调色，深色使用主题暗面并加亮色描边；「候选窗口」页用真实文字实时画四张色系卡，每张同时展示浅 / 深两条预览，不嵌静态图片。
- 设置正文、主题卡文字、候选窗口与状态条共用用户选择的字体；所有界面图标走独立的图标字族或矢量路径，不能被候选字体替换。
- 悬浮状态条的当前模式画成 28 pt 强调色方章：白色「中 / A」，中文态右上角加输入色圆点；双拼不写长方案名，只显示「鹤 / 自 / 微 / 搜」。
- 任务栏 / 语言栏的 16 px 模式图标使用单独绘制的「中 / A」，不直接缩小主图标。
- 安装包、开始菜单和设置程序的系统级应用图标继续使用默认「字在蓝」，保持任务栏与系统搜索中的品牌识别；窗口内部 Logo 才随主题换色。卸载入口可用单色轮廓版；不要把下载箭头、箱子或 UAC 盾牌画进主图标。
- Windows 高对比模式由系统颜色接管；不能只靠颜色表达云端、生词或纠错状态。

## 兼容边界

品牌切换不同时迁移 `%APPDATA%\Qingjian`、`%LOCALAPPDATA%\Qingjian`、`Program Files\Qingjian`、`.qj` 格式名、Cargo 包名、可执行文件名与注册标识。它们需要单独的迁移方案，避免升级后丢学习数据、重复启动 Server 或留下两个输入法 profile。

## 分阶段落地

第一阶段建立统一基线：产品名、主图标、安装包 / 开始菜单、设置窗口、候选窗、状态条和语言栏都切到「字在」；内部兼容标识不动。

第二阶段补齐会随界面状态变化的品牌体验：

- 设置页直接复用渲染器 `Palette` 展示四套色系的浅 / 深实时预览；明暗始终跟随系统，不再单独选择；
- 设置程序、候选窗与悬浮状态条读取同一个色系配置并热切换；
- 安装向导使用独立的 164:314 浅 / 深品牌画面，Inno Setup 以 `modern dynamic` 跟随 Windows 明暗模式；
- 安装向导画面与主图标都由 `assets/icon/generate.py` 生成，避免手工导出版本漂移；
- 主题预览有文字标签和候选内容，颜色不是识别状态的唯一手段。
