## 模糊音

九条：z/zh、c/ch、s/sh、n/l、f/h、l/r、an/ang、en/eng、in/ing。缺省全部关闭。

开启：「设置 → 模糊音」勾选。开启 z/zh 后输入 `zi` 也出 知 / 之，开启 f/h 后输入 `kaiha` 也出 开发。
输入正确的词仍然优先，模糊匹配的词排在其后。韵母三条只对完整音节生效。

## 双拼

四套方案：小鹤、自然码、微软、搜狗。在「设置 → 通用」选择，留空为全拼。

- 拼音行显示解出的全拼（`nihc` → `ni'hao`），学习按全拼记录，切回全拼后同样受益。
- 零声母：小鹤 / 自然码写 `aa` `ai` `ah`（a、ai、ang）一族；微软 / 搜狗写 `o` + 韵母键（`oa` `ol` `oh`）。
- 微软 / 搜狗的 `;` 为 ing：输入拼音时末尾有落单的声母，`;` 作为拼音（`x;` → xing）；其他情况下仍为标点。
- 双拼下 v / u / i 均为音节键，[快捷输入](shortcuts.md) 中的算式与问字只能以 `?` 开头进入。
- 全拼输入 `lue` / `nue` 与词库形式 `lve` / `nve` 等价。双拼统一解为 `lve` / `nve`。
- 已知限制：`lo` 与 `luo` 同键，解为 luo。

## 辅码（小鹤）

辅码是可选的形码筛选：双拼打完一个字之后，接着敲这个字的形码，把同音字一下子缩到几个。

- 开启：「设置 → 通用」里选「小鹤辅码」（需先选双拼方案）。
- 取码：每个字两个码，按部件读音取声母键（阿 = `ek`、栏 = `ms`、你 = `rx`、好 = `nz`）。
  单字取本字两码；**词组取首字第 1 码 + 末字第 1 码**，与词长无关 —— 所以 你好 的辅码是 `r` + `n`，不是 好 的两码。
- 只敲第一码：匹配的排到最前，别的候选还在。
  `lj`（lan）有一百多个同音字，接着敲 `m` → 栏目、栏、榄、阑、婪 排到前面，而 蓝莓、烂漫 这类
  「`m` 是下一个字声母」的词仍留在后面可选 —— 这一键有两种读法，两种都给你留着。
- 敲满两码：只留匹配的。`ljms` → 只剩 栏。两码正好凑成一个合法音节时（正常的双音节连打）不会被当成辅码。
- 大写是「就按辅码算」：任一码大写就强制只留匹配的；**第一码大写还表示反转顺序**
  （`Nr` 与 `rN` 都匹配实际辅码 `rn`），适合记熟了末部件先敲的人。
- 候选旁会标出各自的辅码（`栏 ms`、`蓝 cm`），敲了辅码才显示 —— 不用背，看着选就行。
- 前提：前面的双拼没解完整时，末尾的字母仍按普通拼音处理，不会误触发。
- 辅码键不是要打的内容：回车上屏的字母串不含它，学习也按纯双拼记录；
  选中的候选只盖住前面一段拼音时（`kdfa` 加辅码后选了 开），辅码键跟着这次上屏一起消失，剩下的拼音重新出候选。
- 两码都敲完时拼音行会把辅码段单独画在拼音后面（`ni'hao rN`，画淡一点）；只敲第一码时那一键还在拼音里，不重复画。
- 辅码键与 [临时输入大写字母](../getting-started/keys.md) 冲突：辅码开着时，输入拼音过程中的 `Shift + 字母` 是辅码键；想打大写英文，先按 `Escape` 清掉拼音再打。
