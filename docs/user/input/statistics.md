title: 统计

description: 偏好设置「统计」页的内容：输入的汉字数、词数与上屏次数，以及累计字数折算的书目。
---

「偏好设置 → 统计」列出今天 / 最近 7 天 / 累计输入的汉字数、中文词数、英文词数与上屏次数；
累计字数另折算为「约等于 n 本《某书》」，书目从《道德经》到《平凡的世界》。

数的是上屏的文字：选一个词算一个中文词，整句按词切开数；英文候选与原样上屏的英文词算英文词。

这些只是若干数字，按天记录在本机，不上传，与输入日志无关：关闭或清空日志后统计仍在。
清除方式见 [数据与日志](../help/data-and-logs.md)。
