## 进入英文模式

单击 `Shift`（按下即松开，不与其他键组合）在中 / 英之间切换，字在的任务栏模式按钮同步显示「中」或「A」。
反向同样有效：点击任务栏的「中 / A」图标，字在随之切换（悬浮状态条一并更新）。
`Caps Lock` 只控制大小写：亮起时无论中英模式均直接输出大写英文字母（与微软拼音一致）；`Shift` + 字母同样输出大写。

## 悬浮状态条（Windows）

任务栏的「中 / A」不易察觉时，可另开一条**桌面上的悬浮状态条**：「设置 → 候选窗口」打开「显示悬浮状态条」。它有四格：

| 格 | 显示 | 点击 |
| --- | --- | --- |
| 主题色品牌 Logo | 状态条的拖动区域 | 单击无动作，按住可拖动 |
| `中` / `A` | 当前模式；与其他格共用状态条背景，双拼时旁边显示 `鹤 / 自 / 微 / 搜` | 切换中 / 英，与单击 `Shift` 相同 |
| `，。` / `,.` | 当前模式下标点是否转为全角。中英各记一份，缺省中文全角、英文半角，切换模式时随之切换 | 切换当前模式的全角 / 半角 |
| ⚙ | | 打开设置 |

按住拖动可移到屏幕任意位置，位置会被记住；外观随系统的深浅色与缩放。
它只在当前输入法为字在时显示：切换到微软拼音等其他输入法时收起，切回后再次出现；关闭某个应用不影响它。它与任务栏图标并存。

## 行为

英文模式下**所敲字母直接进入输入框，不出候选窗口**，与未使用输入法时一致：
`Space`、`Enter`、数字键都是它们本来的意思，`kubectl` 这类词不会被任何补全替换，`Tab` 与方向键仍归应用（终端、编辑器里的补全与跳转不受影响）。
字母缺省小写，按住 `Shift` 输出大写。

标点是唯一的例外：缺省半角，需要全角时见上文悬浮状态条。

## 与中文模式的关系

要打英文词不必切到英文模式：中文模式下整段输入为英文词时直接给出英文候选（`hello` 先英文再拼音，勾选「中文候选排在英文词前面」后英文排第二），
拼音不成立时还会补全前缀（`compa` → company）。见 [快捷输入](shortcuts.md)。

按 `Enter` 原样上屏过的英文词（如 `gist`、`python`）会记入个人词表，下次输入时排在首位。
`key`、`id` 这类末尾落单一个字母、既像英文词又可读成拼音的输入，若常选中文词（如「客一」「以的」），中文词排在前面，英文词退后；
勾选「中文候选排在英文词前面」后中文词一律在前。
